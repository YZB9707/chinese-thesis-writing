# 结构与格式：人称、论述句、部件顺序、版面

> 什么时候读：审格式、检查部件顺序与版面；被要求“按论文格式收紧”。
> 来源：第八部分 8.1—8.3、第三部分 3.5。

### 8.1　正文不出现第一人称

- 全文不用“我”“我们”“咱们”。要交代是谁做的，把主语换成非人称的施动者：“本研究”“本次调查”“访谈记录”“观察数据”“XX 学校的一位体育教师”。
- 2.2 那条“每句必须有主谓宾”不变，变的是主语是谁。原来写“我按照批次记录，不记录学生姓名”，正式稿写“本研究按批次记录，不记录学生姓名”。
- 摘要、结论、致谢这三处最容易漏“我们”。写完搜“我”字，逐处改掉，不要留一处例外。

### 8.2　以论述句为主，不用排比，不用感叹号

- 论文的骨架是论述句：给判断，附依据。描写和叙述可以有，但不能成段。一段里连续三句只写“谁做了什么”，这一段就滑成了随笔。
- 整句排比不要用。“既要……又要……还要……”和 2.6 的四字并列是一路，改成一句主句加一处补充。
- 全篇不出现感叹号。强调靠事实和语序，不靠标点。“这项工作非常繁重！”改成“这项工作要在两周内覆盖 1128 名学生”。
- 问句只留一种用法：设问之后立刻自答，见 2.7。除此之外不用问句，尤其不在段首自问。

### 8.3　全文结构与版面

部件顺序固定：题目、摘要与关键词、目录、正文、参考文献、致谢、附录（有才放）。编号章“第一章”、节“1.1”、三级“1.1.1”，最多三级。表题在表上，图题在图下，连续编号，正文第一次提到写“见表 1”。版面见 3.5：A4，上下 2.5、左右 3.2 厘米，宋体小四，行距 1.5，首行缩进 0.85 厘米。

| 部件 | 必须有的内容 | 常见缺项 |
|---|---|---|
| 题目 | 研究对象、方法、范围各占一样 | 只写“浅谈……”，看不出对象与范围 |
| 摘要 | 目的、方法、结果、结论各一句 | 只写背景，没有结果与结论 |
| 关键词 | 3—5 个，覆盖对象与方法 | 写成一整句话 |
| 目录 | 到三级，页码与正文一致 | 手工输入，改稿后没更新 |
| 正文 | 五章上下，第四章是结果与分析 | 结果章没有数，只剩描述 |
| 参考文献 | 条条在正文有落点 | 只列不引，或引了不列 |
| 致谢 | 一段，不写成绩与收益承诺 | 没有，或写成客套长文 |

交稿前照 6.1 的方法转成 PDF 逐页看。重点三处：标题有没有孤零零落在页底，表格有没有跨页，目录页码与正文对不对得上。这三处对不上，老师翻两页就知道稿子没通读。

### 3.5　版面参数

| 项目 | 取值 |
|---|---|
| 纸张与边距 | A4（21×29.7 厘米），上下 2.5、左右 3.2 厘米 |
| 正文 | 宋体小四（12 磅），行距 1.5 倍，首行缩进 0.85 厘米 |
| 一级标题 | 宋体四号（14 磅），不缩进 |
| 二级、三级标题 | 宋体小四加粗，缩进 0.4／1.2 厘米 |
| 参考文献 | 五号（10.5 磅），悬挂缩进 |
