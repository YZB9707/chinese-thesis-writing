# 开题报告：表格型模板的克隆

> 什么时候读：要写开题报告；学院给了 Word 模板要求套版。
> 来源：第三部分 3.1—3.4。

## 第三部分　开题报告：结构与套版

### 3.1　有学院模板时，克隆模板，不要另造

多数学院的开题报告是表格型：封面（校徽、手写体校名、下划线填空）＋填表说明页＋一张大表格。表格里固定几个小节，最后是参考文献、其他说明和三栏意见（指导教师、开题小组、院系）。

正确做法是复制模板文件、在原文件上替换文字，不要另起一份重排。校徽图片、下划线填空、表格边框、页脚页码，只有克隆才保得住。模板里的旧内容要全部清掉，包括附录里的旧问卷。

| 模板部件 | 处理方式 |
|---|---|
| 封面 | 替换姓名、学号、院系、专业、年级、指导教师与日期；填空线保留空白，由本人手填 |
| 填表说明页 | 原样保留（属于学院表格的一部分，不是作者内容） |
| 表格正文 | 清空后按六个小节重写，字号行距照模板 |
| 主要参考文献 | 替换为本研究的文献，条数与正文引用一一对应 |
| 其他说明 | 留白，或只放学院要求的内容；不要写助手式的说明文字 |
| 三栏意见 | 保留标题与签字行，签名行右对齐 |

### 3.2　六个固定小节

表格型模板的正文一般分六节，顺序不要调换：

- 一、选题依据：政策依据＋现实问题＋已有研究的缺口，三段以内说清。
- 二、研究目的：三件事，一句一件，动词开头。
- 三、研究意义：3.1 理论意义、3.2 实践意义，各一段，不要互相重复。
- 四、文献综述：4.1 相关概念界定、4.2 国内研究现状（可按制度演进、实施现状、执行过程分）、4.3 研究述评。
- 五、拟研究的主要内容和思路：先总述段，再列章节目录（见 3.3）。
- 六、研究对象与研究方法：研究对象、学校概况、选点理由、研究方法逐条。

### 3.3　“五、拟研究的主要内容和思路”的写法

这一节最容易被退稿，因为它既是“要研究什么”，也是“打算怎么写”。必须先有一段总述，再列章节目录，缺一不可。总述的句式可以套用：

本文聚焦于〈研究对象〉，并以此作为研究对象，从〈调查地点〉选取〈调查对象〉
作为调查对象，主要采取文献资料法、问卷调查法、访谈法、观察法、数理统计法
等方法进行研究与调查，最后对所收集的数据资料进行整理和分析并得出结论。
主要研究内容如下：
第一章　前言（1.1 选题依据／1.2 研究目的／1.3 研究意义）
第二章　文献综述
第三章　研究对象与方法（3.1 研究对象／3.2 研究方法及其分项）
第四章　结果与分析（4.1—4.4，可按测试组织、器材与操作、数据流程、教师与学生分）
第五章　结论与建议

目录列到三级即可。层级缩进要能看出来：章与节缩进 0.4 厘米，三级标题缩进 1.2 厘米。

### 3.4　研究对象一节要写三样东西

- 学校概况：年级、班数、学生数、体育教师人数（在编与兼职分开）、场地条件。
- 派生指标：班均人数＝学生数÷班数；师均学生数＝学生数÷在编教师数。这两个数字本身就是第四章问题分析的起点。
- 选点理由三条：能进现场、规模与条件有代表性、本学年有完整测试与上报。

涉及对比研究时，两所学校的材料必须用同一套表格、同一份访谈提纲，否则数据不可比。
